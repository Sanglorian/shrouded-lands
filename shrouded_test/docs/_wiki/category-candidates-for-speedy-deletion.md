There are a few, special cases that {{SITENAME}} speedily deletes articles or files "on sight". This page lists articles using the {{t|speedydelete}} template. Before speedily deleting an article, ensure that it meets the [criteria for speedy deletion](/wiki/projectcandidates-for-speedy-deletion/). For any discussion of pages listed for speedy deletion, please use the talk page of the article in question. 

Deleted articles are automatically listed in the [deletion log](/wiki/speciallogdelete/).
