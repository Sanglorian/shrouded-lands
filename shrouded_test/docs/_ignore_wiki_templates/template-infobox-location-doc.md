==Description==
To use this template, copy the following code and fill in the appropriate fields.

==Syntax==
<pre>
{{infobox location
 | title         = 
 | image         = [e.g. "Example.jpg"]
 | imagewidth    = [e.g. "150"] [default: 210 pixels]
 | imagecaption  = 
 | map           = [e.g. "Example.jpg"]
 | mapwidth      = [e.g. "150"] [default: 210 pixels]
 | mapcaption    = 
 | type          = 
 | level         = 
 | location      = 
 | inhabitants   = 
}}
</pre>

==Samples==
<pre>
{{infobox location
 | title         = Flora Island
 | image         = Example.jpg
 | imagecaption  = The island
 | map           = Example.jpg
 | mapcaption    = Zone map
 | type          = Contested
 | level         = 1-5
 | location      = Earth
 | inhabitants   = Stompy Humans, Drinky Bees
}}
</pre>
