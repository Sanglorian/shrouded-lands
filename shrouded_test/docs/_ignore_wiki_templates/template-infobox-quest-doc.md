==Description==
To use this template, copy the following code and fill in the appropriate fields.

==Syntax==
<pre>
{{infobox quest
 | title         = 
 | image         = [e.g. "Example.jpg"]
 | imagewidth    = [e.g. "150"] [default: 210 pixels]
 | imagecaption  = 
 | start         = 
 | end           = 
 | prerequisites = 
 | level         = 
 | location      = 
 | rewards       = 
 | previous      =
 | next          =
}}
</pre>

==Samples==
<pre>q
{{infobox quest
 | title         = Flowers of Justice!
 | image         = Example.jpg
 | start         = Chrys
 | end           = Geran
 | prerequisites = None
 | level         = 5
 | location      = Earth
 | rewards       = Justice-Wrought Petals
 | previous      = A
 | next          = C
}}
</pre>
