# Wiki asterisk audit

This report lists every wiki-page line that starts with `* *` and classifies it into one of three fix categories plus a “no change” category. The classification uses surrounding list context and formatting cues (bold labels, leading images, or leading italics):

- **Category 1 (Indented bullet)**: The line is a sub-point under a preceding list item. Proposed fix: convert `* *` to an indented bullet (`  * `).
- **Category 2 (Bold term/label)**: The line is a field/label line that already uses bold formatting (e.g., `**Region:**`). Proposed fix: remove the list marker and start the line with `**`.
- **Category 3 (Leading image)**: The line starts with an image immediately after the extra list marker. Proposed fix: remove the leading `* *` so the image renders inline.
- **Category 4 (No change)**: The line is already a valid list item whose text begins with italic emphasis (e.g., a title) and does not need changes.
